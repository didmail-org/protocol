# HPKE compatibility fixture provenance

`hpke-rfc9180.json` selects one vector's scalar values, three encryption records and one export record from the CFRG HPKE test vectors. The selected values and records were compared with the [revision referenced by RFC 9180](https://github.com/cfrg/draft-irtf-cfrg-hpke/blob/5f503c564da00b0687b3de75f1dfbdfc4079ad31/test-vectors.json). These are public cryptographic test inputs; never use them for real identities or content.

The upstream repository identifies its materials as IETF contributions under its [contribution policy](https://github.com/cfrg/draft-irtf-cfrg-hpke/blob/5f503c564da00b0687b3de75f1dfbdfc4079ad31/CONTRIBUTING.md). RFC 9180 is an IRTF-stream document. The precise permission and notice requirements for this selection remain under review; see the project [third-party notices](../../../../THIRD_PARTY_NOTICES). The project's Apache-2.0 license does not relicense this upstream material.
