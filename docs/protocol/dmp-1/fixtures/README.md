# HPKE compatibility fixture provenance

`hpke-rfc9180.json` selects one vector's scalar values, three encryption records and one export record from the CFRG HPKE test vectors. The selected values and records were compared with the [revision referenced by RFC 9180](https://github.com/cfrg/draft-irtf-cfrg-hpke/blob/5f503c564da00b0687b3de75f1dfbdfc4079ad31/test-vectors.json). These are public cryptographic test inputs; never use them for real identities or content.

The full CFRG source file is byte-identical to the earlier [Cisco go-hpke test-vector file](https://github.com/cisco/go-hpke/blob/13744bccfbe21a43be887884a7fc57c6642c6853/test-vectors.json), whose repository includes a BSD 2-Clause license. The selected values and records were compared with that source. The Cisco copyright and license are preserved in the project [third-party notices](../../../../THIRD_PARTY_NOTICES). The CFRG repository also identifies its materials as IETF contributions; RFC 9180 is an IRTF-stream document. The project Apache-2.0 license does not relicense this upstream material.
